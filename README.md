# SWIR 論文導讀網站

網站：https://nlk12367.github.io/405-1006/

20 頁簡報重寫稿與可編輯 PPTX。內容包含 SWIR 背景、偏振量測、原文實驗圖解讀、限制與免費光學模擬規劃。

主要來源：Hamdoh et al. (2025), *Scientific Reports*, 15, 22577. https://doi.org/10.1038/s41598-025-06757-5

## 內容與建置

- `index.html`：簡報式逐頁內文與導覽
- `draft.md`：逐頁文字稿
- `styles.css`、`script.js`：網站樣式與導覽互動
- `swir-paper-review-redesigned.pptx`：可編輯簡報，逐頁講稿收錄於備忘稿
- `build.py`：從上一層的 `SWIR簡報重寫版_逐頁內文.md` 產生頁面

GitHub Pages 使用 `main` 分支根目錄發布。未上傳原始論文 PDF。
